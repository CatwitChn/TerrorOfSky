# Terror of Sky

- `lobby/` 是游戏入口，负责建房、选边和准备。
- `index.html` 是大厅加载的战场页面，负责输入、画面和仪表。
- `server/` 是独立命令行服务端。Windows x64 发布包解压后用 `start-server.cmd` 启动。 [部署说明](server/README.md)

## 本地开发

使用 Node.js 22 或更高版本。首次安装依赖后，在项目根目录运行本地服务。

```powershell
npm.cmd ci --prefix server
node tools/local.mjs
```

打开 `http://127.0.0.1:8081/lobby/`。浏览器与 WebSocket 共用本机端口。可传入 `--port 8082` 指定其他端口。Linux 或 macOS 上使用 `npm` 安装依赖。

Windows 上安装依赖后可双击项目目录里的 **本地测试.cmd**，也可以用桌面的 **Terror of Sky 本地测试**。启动器可从 `.local/node/node.exe`、系统 Node.js 安装目录或 PATH 找到 Node.js，然后启动或复用本地服务，并打开大厅。默认端口是 8081，旧版服务或其他程序占用时会依次尝试 8082 和 8083。使用项目内 Node.js 时，可运行 `\.\.local\node\npm.cmd ci --prefix server` 安装依赖。启动失败时窗口会保留报错，服务端日志位于 `.local/server.log`。

一个人创建房间并准备后即可开局，空位由 AI 补齐。多人测试可以从两个浏览器窗口加入同一房间。

## 当前联机范围

房主创建房间时选择任务，其他玩家用房间码加入。多佛空战为 4 对 4，对抗空位由 AI 补齐。拦截战斗机支持 1–4 人合作，一波 AI 敌机的数量与开局玩家数相同。

玩家可选 F-15A、Su-27 或 F-14D，并在准备前逐挂点保存最多 4 枚导弹。换队、换机、修改已保存的挂载或掉线会取消准备。短时掉线后可恢复席位，房主退出后会转移权限。

F-14D 的机翼随空速自动改变后掠角。`Q` 在已挂载的红外弹、半主动雷达弹和主动雷达弹之间切换。AIM-54C 通过现有雷达锁定流程发射，进入游戏内主动追踪阶段后可以独立跟踪。

全员准备后，房主可开始合作任务。多人对抗还要求两队都有人。服务端统一计算飞行、雷达、武器和胜负。按 Esc 可回大厅，房主可以结束本局或在对局结束后返回准备。

房间和对局保存在内存中，服务重启会清空。新版大厅使用 0.5.0 服务端。

修改画面或 HUD 后刷新本地网页。修改飞行或战斗规则时编辑 `server/simulation.mjs`，随后重启本地服务。战场从服务端读取仪表和渲染所需的规则数据。
